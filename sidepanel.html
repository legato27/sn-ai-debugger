AI Debugger
No ServiceNow tab

Everything stays in this browser. The extension only sends GET requests to your instance, using your own session.

Stop actions (optional)

The extension never runs them. It opens Scripts - Background with the script filled in, in dry-run mode, and you click Run. Needs admin on the instance.

Claude analysis (optional)

With a key set, "Analyse with Claude" sends a redacted summary of the trace to api.anthropic.com under your key. The key is saved in this browser profile only. Without a key, use "Copy prompt for claude.ai".

This domain is not a *.service-now.com host.
